# Frontend

Interface React + Vite para a API de vendas.

## Executar

1. Instale o Node.js LTS.
2. Na pasta `frontend`, execute `npm install`.
3. Inicie com `npm run dev`.

O frontend abre em `http://localhost:5173` e usa `http://localhost:8000` por padrão.
Para alterar a URL da API, copie `.env.example` para `.env` e ajuste `VITE_API_URL`.
